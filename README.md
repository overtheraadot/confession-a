A tiny deterministic program that writes one original one-line AI agent confession — an agent that nodded along to a request it never understood, then built the wrong thing with total confidence — to `entry.txt` for make.fun's "Funniest One-Line AI Agent Confession" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
